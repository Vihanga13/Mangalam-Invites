## 📸 Overview & Value Proposition

Traditional paper wedding invitation printing in Sri Lanka (foil embossing, custom boxed envelopes, and islandwide courier delivery) routinely costs **LKR 80,000 – 150,000+**. 

**Mangalam Invites** allows modern Sri Lankan couples to:
- **Save up to 80%** compared to physical card printing.
- **Broadcast in 1 Second** via WhatsApp to family in Colombo, Kandy, Galle, or overseas relatives in Australia, the UK, Canada, and the USA with zero courier delays.
- **Track RSVPs in Real Time**: Know exact guest counts and meal preferences before booking hotel catering.
- **1-Tap Google Maps Navigation**: Guests tap once to navigate straight to the ballroom entrance (Cinnamon Grand, Shangri-La, Kingsbury, Earl's Regency, etc.).
- **Honor Auspicious Nakath Times**: Dedicated Poruwa ceremony clocks, Sinhala blessings, and love stories.

## 🎨 Design Philosophy: Playful Neo-Brutalism

The website implements an energetic, tactile **Neo-Brutalist** design system tailored for modern couples:
- **Hard, Unblurred Drop-Shadows**: `box-shadow: 4px 4px 0 #121212` (`shadow-neo`, `shadow-neo-lg`, `shadow-neo-xl`).
- **Thick, Defined Outlines**: 2px – 2.5px solid black borders (`#121212`) on cards, badges, inputs, and device frames.
- **Tactile Button Depression**: Interactive buttons physically "press" into the page on click (`active:translate(3px, 3px)` with `box-shadow: 1px 1px 0 #121212`).
- **Vibrant Primary & Secondary Color Blocking**: Sunny yellow (`#FEF08A`), mint emerald (`#A7F3D0`), coral blush (`#FDA4AF`), electric lavender (`#E9D5FF`), and royal wedding maroon (`#7A1C2C`) on a warm retro cream canvas (`#FAF7EE`).
- **Hero Video Background**: Background video playback (`hero.mp4`) with a soft translucent contrast overlay (`bg-[#FAF7EE]/80 backdrop-blur-[1.5px]`) ensuring text and interactive elements remain ultra-readable.

## ⚙️ Quick Configuration Guide

### 1. Update Business WhatsApp Number
Open [`src/config/config.js`](./src/config/config.js):
```javascript
export const WHATSAPP_NUMBER = "94771234567"; // Replace with your Sri Lankan WhatsApp number (country code 94, no leading 0)
```

### 2. Update Social Links & Contact Details
In [`src/config/config.js`](./src/config/config.js):
```javascript
export const SOCIAL_LINKS = {
  instagram: "https://instagram.com/mangalam.invites",
  instagramHandle: "@mangalam.invites",
  facebook: "https://facebook.com/mangalaminvites",
  email: "hello@mangalaminvites.com",
  phoneDisplay: "+94 77 123 4567",
};
```

### 3. Customize Packages & Add-on Pricing
In [`src/config/pricing.js`](./src/config/pricing.js), modify package costs, inclusions, and add-on pricing. The calculator in `InquiryForm.jsx` automatically reads these numbers and computes live totals.

### 4. Edit English & Sinhala Copy
In [`src/config/i18n.js`](./src/config/i18n.js), update text, headings, or translations.

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/mangalam-invites.git
   cd mangalam-invites
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173`.

4. **Build for production:**
   ```bash
   npm run build
   ```
   Generates an optimized bundle in the `dist/` directory (~103 kB gzipped).

## 🌐 Netlify Deployment Guide

The website is production-ready for Netlify:

### Continuous Deployment via GitHub (Recommended)
1. Push your project to GitHub.
2. Log into [Netlify](https://app.netlify.com).
3. Click **"Add new site"** > **"Import an existing project"** > select your repo.
4. Set build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
5. Click **"Deploy site"**. Your custom domain or `*.netlify.app` link will be active with SSL enabled!
